# GitHub and Markdown: A Short Guide

You will use GitHub as the online home for your course portfolio. You do not need to install Git or use the command line.

## Repositories, Folders, and Files

A **repository** is the complete course project. It contains folders and files, much like a folder on your computer.

- Select a folder name to open that folder.
- Use the path near the top of the page to see where you are and return to a higher-level folder.
- Select a filename to open the file.
- Use **Add file** to create a file or upload one from your computer.

Many folders contain a file named `README.md`. GitHub automatically displays this file beneath the folder's list of files. It therefore serves as the introduction or instructions for that folder. Read it before adding or editing material.

## Why a File Looks Different When You Edit It

Files ending in `.md` use **Markdown**, a simple way to format text. GitHub normally shows the formatted version. When you select the edit button, you see the underlying Markdown symbols instead.

For example, this Markdown:

```markdown
# Main Heading

## Smaller Heading

This is **important** text.

- First item
- Second item
```

is displayed with headings, bold text, and a bulleted list. While editing, use the **Preview** tab to check how the formatted file will look.

## Markdown Basics

```markdown
# Main heading
## Section heading
### Smaller heading

**bold text**
*italic text*

- Bulleted item
- Another item

1. First numbered item
2. Second numbered item

[Link text](https://example.com)
```

Leave a blank line between paragraphs and before a list. For this course, these basic elements will usually be enough.

## Saving Your Work

On GitHub, saving a change is called making a **commit**.

1. Select **Commit changes**.
2. Enter a short description of what you changed, such as `Complete Week 2 journal`.
3. Select **Commit changes** again.

After committing, reopen the file and check that the content and formatting appear as expected.
