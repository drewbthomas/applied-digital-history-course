# Applied Digital History

This repository contains tutorials, datasets, and supporting materials for **Applied Digital History: Methods and Projects** at the University of Salzburg.

The course provides practical experience in applying digital methods to historical research. It is organized around a recurring sequence:

> **Materials → Processing → Presentation**

Students will examine how historical sources become structured data, how computational tools transform that data, and how analytical results can be presented as historical evidence. Particular attention will be paid to provenance, missing data, uncertainty, validation, and the distinction between a computational result and a historical interpretation.

## How the Course Works

Each week introduces a different tool or practical skill. Students will normally complete the assigned tutorial before class so that they can work at their own pace. Class meetings will focus on:

- Discussing difficulties and unexpected results.
- Comparing the effects of different methodological decisions.
- Examining digital history projects that use the week's method.
- Troubleshooting common problems.
- Applying the method to individual research projects.

No previous programming experience is required. Browser-based tools will be used wherever possible.

New tutorials will be added during the semester. Students should always use the current version in this repository rather than copying the complete course repository into their personal work.

## Student Portfolios

Each student will create a separate private GitHub repository from the student portfolio template provided in class. This personal repository will contain:

- Weekly practical work.
- Output files and visualizations.
- The weekly journal.
- Project materials and processing documentation.
- The final poster and short report.

This course repository contains the instructions and supplied material. Student work should be uploaded to the corresponding folder in the student's personal portfolio repository.

No command-line Git knowledge is required. Course repositories can be created, edited, and updated through the GitHub website.

## Weekly Workflow

For each tutorial, students should:

1. Read the instructions in this repository.
2. Download any required starter files.
3. Complete the exercise using the specified tool.
4. Preserve the original material alongside any transformed version.
5. Upload the required files to the corresponding folder in the personal portfolio.
6. Complete the weekly journal entry.

The journal should distinguish between:

- **Evidence:** what the sources or data show.
- **Inference:** what can reasonably be concluded from the result.
- **Interpretation:** the larger historical explanation.
- **Speculation:** plausible ideas not established by the available evidence.

## Final Project

Each student will use a historical dataset to design and conduct a small digital history project. The project must include a historical question, source and data criticism, at least one substantial digital method, validation of the results, and explicit discussion of limitations.

The final outputs are:

- An academic research poster.
- A short written report.
- A documented GitHub project containing the materials, processing steps, outputs, and validation.

Students are not expected to use every method introduced in the course. A carefully designed project using one appropriate method is preferable to a superficial project combining several tools.
